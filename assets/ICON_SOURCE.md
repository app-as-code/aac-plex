# Icon source

Icons are downloaded from the selfh.st icon collection (repository `selfhst/icons`,
served via jsdelivr), which provides ready-made logos for self-hosted applications.
No icon was drawn or modified by hand.

| File in this repo | Upstream file | Used for |
|---|---|---|
| `icon.svg` | `svg/plex.svg` | Default (colored logo on dark tile) |
| `icon-light.svg` | `svg/plex-dark.svg` | Dark-colored logo for light backgrounds |
| `icon-dark.svg` | `svg/plex-light.svg` | Light-colored logo for dark mode |

Download URLs:

- https://cdn.jsdelivr.net/gh/selfhst/icons/svg/plex.svg
- https://cdn.jsdelivr.net/gh/selfhst/icons/svg/plex-light.svg
- https://cdn.jsdelivr.net/gh/selfhst/icons/svg/plex-dark.svg
